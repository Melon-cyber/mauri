# Происхождение ресурсов

- **Знак Mauri** (`app/src/main/res/drawable-nodpi/mauri_mark.png`) и **иллюстрации коллекций** (`night_drive.png`, `collection_moon.png`, `favorites_flowers.png`, `collection_road.png`, `collection_arch.png` в той же папке) созданы для этого проекта генератором изображений, без изображений-референсов. Это не обложки музыкальных релизов. Распространяются вместе с проектом по той же лицензии GPL-3.0-or-later.
- **Шрифт Manrope** — неизменённый variable TTF из Google Fonts, SIL Open Font License 1.1 (`app/src/main/assets/licenses/Manrope-OFL.txt`).
- **Значки интерфейса** — Material Icons, Apache-2.0.
- **Обложки песен** в приложении загружаются из метаданных источников и в репозиторий не входят. На снимках экрана в `docs/screenshots/` показаны демонстрационные данные тестов.
