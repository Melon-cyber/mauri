# История версий

## 0.7.2
- Очередь в режиме «Вразброс» и «Свежий микс» снова показывает все песни, а не только несколько последних.

## 0.7.1
- Первый открытый релиз. В настройках появилась ссылка «Исходный код» на этот репозиторий.

## 0.7.0
- Подготовка к открытому исходному коду: README, автосборка на GitHub, шаблоны Issues.
- Релизная сборка сжимается R8: APK стал примерно вдвое меньше.
- После неожиданного закрытия приложение предлагает поделиться отчётом об ошибке. Отчёт отправляется только вручную.

## 0.6.3
- Новая подгонка текста: несколько отмеченных строк вместо одного сдвига, поэтому текст идёт в такт даже в клипах со вставками.
- Перемешивание стало переключателем, как в Spotify: выкл → «Вразброс» → «Свежий микс».

## 0.6.2
- Очередь: перетаскивание за ручку, свайп влево убирает песню, свайп вправо делает её следующей.

## 0.6.0
- Выбор другой версии записи, предзагрузка следующей песни, тексты офлайн, заполнение строки при пении, отправка строки картинкой.
- Плавный переход между песнями, выравнивание громкости, эквалайзер.
- Интерактивный виджет, Android Auto, голосовой запуск.
- Импорт ссылок Яндекс Музыки и Apple Music, «Микс дня», умные подборки, итоги года, перенос одним файлом.
- Перевод текста на русский.

## 0.5.0 и раньше
- Полноэкранный текст песни, статистика «Твой ритм», загрузки для офлайна, импорт плейлистов Spotify, очередь с режимами, рекомендации по знакомым исполнителям.
